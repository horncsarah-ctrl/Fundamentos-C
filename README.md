# 💻 Fundamentos de C

Este repositório reúne exercícios e projetos desenvolvidos durante meus estudos dos **fundamentos da linguagem C**, com foco no aprendizado de lógica de programação e dos principais conceitos da linguagem.

## 📖 Sobre

Este projeto foi criado para registrar minha evolução no aprendizado de **C** durante a graduação em **Ciência da Computação**.

Ao longo do repositório, são apresentados exercícios desenvolvidos durante as aulas e atividades da faculdade, explorando conceitos fundamentais de programação por meio de aplicações práticas.

O objetivo é utilizar este espaço para praticar, testar diferentes soluções e acompanhar minha evolução ao longo do aprendizado da linguagem.

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/horncsarah-ctrl/Fundamentos-C.git
```

Entre na pasta:

```bash
cd Fundamentos-C
```

Escolha o arquivo `.c` que deseja executar e compile utilizando um compilador C, como o GCC:

```bash
gcc programa.c -o programa
```

Depois, execute o programa:

```bash
./programa
```

No Windows, também é possível executar:

```bash
programa.exe
```
